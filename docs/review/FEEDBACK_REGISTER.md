## Status meanings

- **Accepted:** the response is implemented within the current scientific and privacy boundaries.
- **Partially accepted:** a bounded part is implemented and the remainder is stated.
- **Deferred:** useful but requires later evidence, authorization, or resources.
- **Not adopted:** not implemented, with a recorded scientific or ethical reason.

Future entries must retain the original source, distinguish quotations from paraphrases, link the
response to evidence, and state unresolved limitations. AI-assisted project work is not an
independent human review.
