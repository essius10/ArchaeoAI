# Commercial hypothesis register

## Status scale

- `UNTESTED` — no adequate external evidence has been collected.
- `WEAK SUPPORT` — limited or low-confidence evidence, with material uncertainty.
- `SUPPORTED` — repeated, sufficiently direct evidence across relevant participants; still bounded
  to the observed sample and not equivalent to product-market fit.
- `CONTRADICTED` — credible evidence materially opposes the hypothesis.

Every hypothesis begins `UNTESTED`. Repository design work is not external evidence. Status changes
must cite interaction IDs, include contrary cases, and state the participant denominator.
